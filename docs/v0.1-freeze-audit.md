## Evidence summary
- `--help` shows exactly `scan`, `gate`, `draft-reply`, `escalate`, `report`.
- `find crates ...` and `cargo metadata` both show exactly `crates/review-firewall` and `crates/rf-core`.
- `rg` over `crates/rf-core` found no filesystem, subprocess, or GitHub client logic.
- Real-repo `scan -> gate -> draft-reply -> escalate -> report` completed with exit code 0 while emitting `STATUS: ERROR` and `REASON:` when GitHub was unavailable.
- `.review-firewall/run/latest.json` points to a run directory containing all six expected artifacts.

## Mismatches fixed in Phase 6
- `git status --short` fallback could drop the first character of modified paths; fixed in [`crates/review-firewall/src/adapter/git.rs`](../crates/review-firewall/src/adapter/git.rs) and pinned in [`crates/review-firewall/tests/adapter_and_io.rs`](../crates/review-firewall/tests/adapter_and_io.rs).
- Issue-comment pseudo-thread behavior is intentionally conservative; top-level comments stay independent unless an explicit shared thread id exists, and that behavior is documented in [ARCHITECTURE.md](./ARCHITECTURE.md), [README.md](../README.md), and [README_JA.md](../README_JA.md).
- Freeze-time deferrals were implicit; made explicit in [DEFERRED.md](../DEFERRED.md).

## Deliberate deferrals beyond v0.1
- Further evidence extraction tightening.
- First-class downstream use of top-level `reviewDecision`.

## Release notes bullets
- Local-first Rust CLI for compressing PR review noise into typed, auditable signals.
- Exactly five commands: `scan`, `gate`, `draft-reply`, `escalate`, `report`.
- Deterministic review classification, blocker extraction, and escalation without LLM-dependent core logic.
- Stopless artifact writing with `STATUS:` and `REASON:` on partial/error paths.
- Windows-friendly run pointer via `latest.json` instead of symlinks.
- Optional Nix contributor environment with release-binary-oriented distribution.
